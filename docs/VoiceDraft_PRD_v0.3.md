# VoiceDraft（推特助手）产品需求文档 v0.3 · 当前产品

> 2026-11-13 整理。v0.2（`VoiceDraft_PRD_v0.2.md`）是最初的规划；这一版按**现在线上真实在跑的功能**重写，并记下 v0.2 之后平台方做的所有决定。两份有冲突时以这一份为准。

**一句话**：学会客户本人的文风，帮他在 X（推特）上写、发、回复，绝大部分操作在 TG 机器人里点按钮完成；按次扣 USDT 余额，不收月费。

线上地址：`https://tuiter-production.up.railway.app`（Railway 新加坡）。TG 机器人由服务器运行。

| 方面 | v0.2 的设想 | 现在 |

## 2. 合规原则（不变，硬性）

- 只用 X 官方 API，不爬 X、不用浏览器自动化、不登录客户的 TG 个人号。
- 不做自动私信、自动关注、自动点赞、自动转推。
- 自动回复只针对 **@我 和回复我帖子的人**；给关注的人的回复永远是「候选」，**客户本人点了才发**（X 自动化规则禁止对没找你的人自动回复）。
- 改写别人的内容要防洗稿：和原文相似度 ≥ 67% 时提醒；自动发帖里 X 推文来源 > 50%、其他来源 > 67% 不发并退款。
- App 本身**不设发帖条数上限**（平台方决定：我们是 API 助手，不是 X 的风控），由 X 自身规则约束。
- 推主数据只来自我们自己客户授权的 X 账号；公开排行要本人主动开启，行业平均要够 5 个账号才显示。

## 3. 用户和角色

- **客户**：注册网页账号（邮箱），绑定 TG（一键链接 / 二维码），连接自己的 X（OAuth 2.0）。每个 X 账号、每个 TG 账号只能绑一个客户。
- **团队成员**：见 §5.9。
- **平台方 / 管理员**：环境变量 `ADMIN_EMAILS` 里的邮箱；没设时是最早注册的账号。管理员默认不扣费。所有平台参数在网页「后台」（/admin）改，不改代码。

## 4. TG 机器人（主入口）

底部 6 个按钮，新功能放进已有的组，不再加底部按钮：

| 按钮 | 里面有什么 |
|---|---|
| ✍️ 写推文 | 短推（3 条候选、改写、引用推文）、长文三种形式、从灵感池写 |
| 💬 回复 | @我 的回复候选、给关注的人写回复候选及其设置 |
| 🤖 自动发 | 自动发帖设置、信息源、频道订阅、待确认的自动帖、热点提醒设置 |
| 📂 我的内容 | 草稿、定时队列、发布失败重试 |
| 💰 余额 | 余额与「预计还能发约 N 条」、充值、流水、🎁 签到、邀请好友 |
| ☰ 更多 | 文风（风格卡 / 素材 / 盲测 / 账号记忆）、推广链接、X 账号与书签、团队、数据和排行（含发帖效果）、每日日报、帮助 |

- 新用户三步上手卡：绑定 TG ✓ → 连接 X → 导入素材；做完自动消失。
- **频道门槛**：必须加入后台设置的频道 / 群（最多 3 个，机器人需是管理员）才能用；查询出错时放行；管理员不受限。
- 防刷：每个会话 10 条/10 秒、40 条/分钟，超了先警告再静默，屡犯临时封禁（10 分钟起逐级加长）。

## 5. 功能

### 5.1 素材与风格卡
- 素材：粘贴、上传文件（含 X 存档、CSV）、TG 转发。素材够了生成**风格卡**（代码统计指标 + AI 定性描述 + 代表例句）。
- 修改反馈：客户改过的候选立即作为示例影响下一次；累计修改后 AI 总结进风格卡，可回滚。
- 风格盲测：混入本人原文和 AI 写的，让本人猜，误判率是「像不像」的北极星指标。

### 5.2 账号记忆
定位、常聊、一贯观点、反对观点、表达方式、不碰的话题，由 AI 从素材和已发帖子总结；所有生成都带上，连同最近发过的 12 条防重复。有风格卡后首次整理，本人推文每多 10 条再整理一次；客户手改过的只增补不覆盖。不收费，每天限 10 次。

### 5.3 起草
- 短推：3 条整条候选，可换一批、改写；可选带推广链接。
- 长文三种：**单条长推**（100–300 字，默认；超 280 加权字数提示需 X Premium）、**串推**（提纲 → 全文 → 逐条改写，可加 1/n）、**X 长文**（提纲 → 全文，含配图位；X 没有长文接口，复制到 X 自己发）。
- X 加权字数：中文按 2 计，按 twitter-text 规则校验。
- 每条候选显示**质量分**（0–100，纯代码：AI 腔词、长度和习惯、和最近发过的重复）。

### 5.4 发布
- 立即发、定时发；定时帖锁定排程时用的 X 账号。串推中途失败只收已发出部分，重试补差价。
- 草稿自动保存，可继续编辑。

### 5.5 灵感池与信息源
- X 书签同步、按文风写引用推文（确认后发）。
- TG：转发给机器人即收录；订阅公开频道；把机器人拉进自己的群当信息源。
- 网站（自动发现 RSS）、论坛列表页、单篇链接、X 用户主页（官方 API，按条收费）。遵守 robots.txt，只读公网地址。
- 跨来源去重：72 小时内别的源收过、重合 ≥ 60% 的不再收。

### 5.6 自动发帖
信息源有新内容 → 按文风写一条 → **全自动**排进定时，或**先确认**推到 TG。可设每天上限、间隔、时段、时区；只用 48 小时内的原文（6 小时–7 天可调），同一来源每天最多 2 条，订阅前已有的内容不发。全自动模式下质量分 < 60 的改为等确认。

### 5.7 回复
- **@我**：按间隔拉取，写好 3 条候选推到 TG，点一下发出（目前不会自动发出回复）。
- **给关注的人**：读关注时间线（X 没有「为你推荐」的接口），按指定账号 / 关键词挑帖，每位作者 24 小时最多 1 条，每天上限默认 10；**只给候选，必须人点**。

### 5.8 推广链接
保存 TG 群、QQ 群等链接，起草、长文、回复时可选带上。带链接的帖子 X 收费高，单独计价。

### 5.9 团队
- 共用钱包 = 所有者自己的余额；成员用的记在所有者名下并写明是谁。每位成员可设每天 / 每月上限（北京时间），用完后按设置改扣个人余额或直接停。
- **官号审批**：成员投稿（/submit），所有者或管理员在 TG 点「通过 / 改 / 驳回」，通过后用官号发出或定时。
- 门槛：所有者余额不低于 **20 USDT**（后台可改）才能建团队、邀请、加入；低于时暂停共用，充值后自动恢复，所有者自己不受影响。
- 所有者只看得到成员的花费，看不到成员的草稿和账号。

### 5.10 签到和邀请
- 奖励是单独的「赠送额度」：扣费时先用，不可提现，最后一次获奖后 90 天作废没用完的部分；显示为「≈N 条」。
- 签到：每天 ≈1 条（0.03），连签 7 天再加 ≈3 条（0.09）。**没充过值的人奖励进存钱罐**（上限 1 USDT），第一次充值后一起到账。
- 邀请：`t.me/<机器人>?start=ref_<码>`。好友**首充到账后**才发：邀请人得首充的 10%（最多 5 USDT），好友额外得 1 USDT。同一 TG / 同一 X / 自己邀自己不发；付款钱包相同进人工审核；每人 30 天 20 个后转人工审核。
- 后台可看漏斗：注册 → 用赠送 → 用完 → 首充 → 复购。

### 5.11 推主数据和周报
每个已连接的 X 账号每天读一次公开数据（粉丝、关注、发帖数等，平台承担费用）。按行业（AI 从风格卡话题归类，客户确认）给出同类平均和名次（同类不满 5 个账号用全站平均）；公开排行榜要本人开启，随时可退出。每周一 10 点在 TG 推周报。

### 5.12 发帖效果和最佳发帖时间
- 帖子发出 **1 天、7 天**后各读一次 X 上的数据（浏览、点赞、转发、回复、引用、收藏；串推看第一条）。只读客户本人发的，官方接口一次 100 条，**费用平台承担**。
- 「📊 数据和排行 → 📈 发帖效果」（/perf）和网页「数据」页：最近 30 天效果最好的 3 条、哪类内容（短推 / 长推 / 串推 / 带链接 / 引用 / 自动发帖）效果好、哪个时段（3 小时一段，按客户时区）发互动最高。
- 至少 6 条有数据、最好的时段明显高于平均（≥ 1.15 倍）才推荐时间；推荐后，定时发布多一个「⭐ 最佳时间」按钮。
- 每日日报里加一行「最近发的里效果最好的一条」。

### 5.13 热点提醒
- 客户自己的信息源里，**3 个以上（可改 2–5）不同的源 12 小时内在说同一件事**，推到 TG：「🔥 热点：N 个信息源都在说这件事」，按钮「✍️ 用它起草」「🔍 提炼要点」「🙈 不感兴趣」。
- 判断方法：开头 400 字的字面重合度 ≥ 35% 算同一件事（比去重的 60% 宽松）；跨来源去重没收进来的那几条也记下来源、算进去。同一个源说两遍只算一个。
- 同一件事只推一次；每天最多推 3 条（可改 1 / 3 / 5）；默认开，「🤖 自动发 → 🔥 热点提醒」（/hot）或网页自动发帖页里改。纯代码判断，不调 AI、不收费；起草按正常价格扣。

### 5.14 每日日报
- 客户：每天早上（默认 9 点北京时间，可改或关闭）推昨日小结和「预计还能发约 N 条」，快用完时提醒充值；昨天没动静不发。
- 平台方：经营日报（注册、首充、充值、消耗、AI / X 成本、毛利、漏斗）。

## 6. 计费

- **只按次扣费**，先扣后做，没做成自动退回（先扣的赠送额度也退回赠送里）。同一个人的并发请求排队扣，余额不会扣成负数。
- **不给客户看单价**：网页和机器人只显示「预计还能发约 N 条」（按「写一条短推 + 发出去」估算）；流水里扣费和退回不显示金额。
- 余额降到**停用线**（默认 1 USDT）就要先充值，免费的 AI 功能也一样（风格卡、盲测、提要点、列提纲、账号记忆，另有每天次数上限）。只有赠送余额、从没充过值的新用户停用线是 0，赠送的 1 USDT 能用完。
- **新用户赠送 1 USDT**：TG 和 X 都绑好（并通过频道门槛）后到账，两件事哪件后做完就在那时发；每个账号、每个 TG、每个 X 账号各只送一次（把领过的 X 解绑再绑到新号不再送）。三步卡上「连接 X」一步写着「连好送 1 USDT」。
- **提醒连接 X**：绑定 TG 满 3 天还没连 X 的，机器人每 3 天提醒一次（还能领赠送的会提到送 1 USDT），最多 5 次；只在用户当地 10–21 点发，带「不再提醒」按钮，屏蔽了机器人的自动停。
- **充值**：USDT，Plasma（另支持 BSC / Polygon / Arbitrum，后台填了地址才显示），**单次最低 10 USDT**。每单给唯一尾数金额，30 分钟内转账，每 30 秒扫链自动入账；金额不对可填交易哈希核对（容差 2 USDT 或 5%）；对不上的到账交管理员处理。同一笔转账绝不入两次账。

## 7. 安全与隔离

- 每位客户数据按 user_id 隔离，有专门的隔离测试；X / TG 一号一绑；OAuth 回调校验登录人。
- 平台密钥（X、TG、AI）在后台填，加密存数据库；加密密钥文件在持久卷上。
- 登录 15 分钟 30 次 / IP，同邮箱错 10 次锁 15 分钟；注册每 IP 每小时 5 个。
- AI 调用每人每分钟 20 次、每小时 300 次，同时最多 2 个；全平台同时 12 个。
- TG webhook 需 ≥ 16 位密钥并去重；`/api/cron/tick` 需 `CRON_SECRET`。

## 8. 技术

Next.js 16 + Drizzle + Postgres（测试用内存 PGlite），AI 用 Claude（Opus 5.5），Docker 部署到 Railway，推到 main 自动上线。每个 PR 跑 typecheck、lint、`npm test`。主要代码在 `src/lib/`：计费 `billing.ts`、充值 `topup.ts` / `chain.ts`、机器人 `telegram.ts` + `tg-bot-*.ts`、自动发帖 `autopilot.ts` / `sources.ts`、团队 `team.ts`、奖励 `rewards.ts`、推主数据 `benchmark*.ts`、定时任务 `scheduler.ts`。
